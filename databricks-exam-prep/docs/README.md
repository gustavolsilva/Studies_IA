## 📁 Arquivo

A pasta `archive/` contém documentação histórica:
- Documentos de iterações anteriores
- Relatórios de melhorias já implementadas
- Design docs antigos

Estes documentos são mantidos para referência, mas não são necessários para o uso atual do projeto.

## 🔄 Manutenção

Ao adicionar nova documentação:
1. Coloque documentos ativos na raiz de `docs/`
2. Mova documentos obsoletos para `docs/archive/`
3. Atualize este README com os novos documentos
4. Mantenha documentos técnicos objetivos e atualizados
