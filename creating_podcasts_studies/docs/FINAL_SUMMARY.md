## 📞 SUPORTE RÁPIDO

**Problema:** Áudios não aparecem  
**Solução:** Execute `python generate_podcast_improved.py`

**Problema:** eSpeak não instalado  
**Solução:** `sudo apt-get install espeak`

**Problema:** Porta 8000 em uso  
**Solução:** Edite server.py (altere porta)
