🚀 COMEÇAR RAPIDAMENTE
═══════════════════════════════════════════════════════════════════════════════

1️⃣  Ativar o ambiente virtual:
    source .venv/bin/activate

2️⃣  Gerar os podcasts:
    python generate_podcast_improved.py

3️⃣  Iniciar o servidor:
    python server.py

4️⃣  Abrir no navegador:
    http://localhost:8000

   ls podcast_audios/
